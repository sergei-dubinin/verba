# Дизайн экранов verba

Макеты трёх экранов и их состояний: вход, список записей, транскрипт — в двух ширинах (телефон 390 px, десктоп 1280 px) и двух темах.

- Требования к интерфейсу: [../design-prompt.md](../design-prompt.md).
- Визуальный язык: дизайн-система verba (цвета, типографика, отступы, радиусы).
- Источник правды для правок — холст «verba — экраны» в Claude. Файлы здесь — выгрузка из него.

## Как пользоваться

- `screens/*.html` — самодостаточные макеты с инлайновыми стилями: открываются в браузере и читаются как спецификация (размеры, цвета, отступы, тексты, состояния).
- При вёрстке брать значения из `tokens.css` — переменные и классы типографики, — а не копировать хексы из макетов.
- Макеты не адаптивные и без логики: это фиксированные кадры. Ссылки между экранами оставлены, чтобы прокликивать сценарий (вход → список → транскрипт).
- Изменился дизайн — правим в холсте и перевыгружаем сюда. Ручные правки макетов потеряются.

## Токены

- `tokens.json` — выгрузка дизайн-системы verba как есть.
- `tokens.css` — те же токены в виде CSS-переменных плюс класс на каждый стиль типографики (`.t-body`, `.t-caption`, `.t-display-lg`, …) и `.tabular` для таймкодов.

## Чего в дизайн-системе пока нет

Введено при отрисовке экранов, в `tokens.css` вынесено отдельным блоком. При обновлении системы — перенести туда.

- **Тёмная тема**: фон `#000000`, карточки и поля `#272729`, элемент на карточке `#2a2a2c`, разделители белым 12 %, приглушённый текст `#a1a1a6`, ссылки `#2997ff` (`primary-on-dark`), заливка главной кнопки остаётся `#0066cc`.
- **Цвета спикеров**: фиолетовый, бирюзовый, оранжевый (и ещё три про запас) — намеренно не синие, чтобы имя спикера не читалось как ссылка. В тёмной теме — осветлённые пары.
- **Красный** для ошибок и деструктивных действий: `#d70015` на светлом, `#ff6961` на тёмном.
- **Слои поверх интерфейса**: затемнение фона `rgba(0, 0, 0, 0.4)` и мягкая тень у шторок, диалогов, алертов и меню — единственное место, где тень допустима; остальной интерфейс плоский.

## Что намеренно не нарисовано

Плеер, волна аудио, поиск, теги, саммари, экспорт, шаринг, аватары спикеров, редактирование текста, настройки, уведомления, онбординг — всего этого в продукте нет.
